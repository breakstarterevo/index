# Youth Intake Commissioner

Double-click `00-build/run_youth_intake_app.bat` from the repository. The launcher
starts a localhost-only commissioner app and opens it with a one-time API token.
Closing the terminal stops the app.

## Source files

- `config.json` stores the 24 GM names and Academy Position Focus values.
- `rules.json` is the versioned simulation rule set.
- `drafts/current.json` is the recoverable, immutable official draft.
- `voids/` retains voided drafts and their written reasons.
- `seasons/` contains immutable published seasons.
- `current.json` points the public builder at the latest published season.
- `used-prospects.json` permanently reserves prospects after publication.

The future-player ratings pool remains `00-build/database/future_players.json`.
Use **Refresh Prospect Pool** in the app to rebuild it from the preferred
`Database` worksheet in `00-assets/spreadsheet/Youth Intake.xlsx`.

## Reproducibility

Official seeds are generated by the local server and cannot be edited. Random
values come from `SHA-256(seed + ":" + counter)`. Bounded selections use rejection
sampling, slot order uses Fisher-Yates shuffling, and every wildcard, focus and
player-selection roll is stored in the season audit.

Publishing is blocked if the standings, app configuration, rules, prospect pool,
or exclusion set changed after the official draft was generated.
